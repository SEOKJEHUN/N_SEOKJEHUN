1. 서비스 개요
서비스명: 레시피랩 (RecipeLab AI)

목적: 냉장고 속 남은 재료를 입력하면 AI가 맞춤형 요리 레시피와 조리 팁을 추천해주는 서비스

타겟 사용자: 자취생, 요보초(요리 초보), 냉장고 파먹기를 실천하는 일반 대중

2. 페이지/섹션 구성 (메뉴 이동 가능)
메인 (Hero) 섹션: 서비스 소개 및 핵심 가치 전달

AI 레시피 추천 섹션: 재료 입력 및 AI 추천 결과 출력 (핵심 기능)

이용 가이드 / FAQ 섹션: 서비스 이용 방법 및 자주 묻는 질문 안내

3. AI 기능 설계
입력: 보유 중인 재료 (예: "계란, 스팸, 김치"), 선호 요리 스타일 (예: "간단한 한 끼")

출력: 추천 요리 이름, 필요한 재료 목록, 단계별 조리 순서, 팁

실패 처리 기준:

빈 입력: 필수 재료를 입력하지 않은 경우 안내 메시지 출력 ("재료를 입력해주세요!")

API 오류: 서버/네트워크 오류 시 안내 메시지 출력 ("일시적인 오류가 발생했습니다. 잠시 후 다시 시도해주세요.")

지연/타임아웃: 응답 지연 시 로딩 스피너 및 대기 안내 표시

async function getRecipe() {
    const ingredientsInput = document.getElementById("ingredients");
    const styleInput = document.getElementById("style");
    const loading = document.getElementById("loading");
    const errorBox = document.getElementById("error-msg");
    const resultBox = document.getElementById("result-box");
    const resultContent = document.getElementById("result-content");

    const ingredients = ingredientsInput.value.trim();
    const style = styleInput.value.trim();

    // 1. 빈 입력 검증
    errorBox.classList.add("hidden");
    resultBox.classList.add("hidden");

    if (!ingredients) {
        errorBox.textContent = "필수 재료를 입력해주세요!";
        errorBox.classList.remove("hidden");
        return;
    }

    loading.classList.remove("hidden");

    try {
        const response = await fetch("/api/recommend", {
            method: "POST",
            headers: { "Content-Type": "application/json" },
            body: JSON.stringify({ ingredients, style })
        });

        if (!response.ok) {
            throw new Error(`서버 오류 발생 (${response.status})`);
        }

        const data = await response.json();
        resultContent.innerHTML = `
            <p><strong>요리명:</strong> ${data.title}</p>
            <p><strong>소요 시간:</strong> ${data.time}</p>
            <p><strong>조리 순서:</strong></p>
            <p>${data.steps.replace(/\n/g, '<br>')}</p>
        `;
        resultBox.classList.remove("hidden");
    } catch (error) {
        errorBox.textContent = "일시적인 오류가 발생했습니다. 잠시 후 다시 시도해주세요.";
        errorBox.classList.remove("hidden");
    } finally {
        loading.classList.add("hidden");
    }
}
④ api/recommend.py (Vercel Serverless Function - Python)
Python
from http.server import BaseHTTPRequestHandler
import json
import os
import openai

openai.api_key = os.getenv("OPENAI_API_KEY")

class handler(BaseHTTPRequestHandler):
    def do_POST(self):
        try:
            content_length = int(self.headers.get('Content-Length', 0))
            body = self.rfile.read(content_length)
            data = json.loads(body.decode('utf-8'))

            ingredients = data.get("ingredients", "")
            style = data.get("style", "일반")

            # OpenAI API 호출
            prompt = f"재료: {ingredients}, 스타일: {style}. 이 재료들로 만들 수 있는 요리 이름, 소요 시간, 조리 순서를 JSON 형태(title, time, steps)로 요약해줘."
            
            response = openai.chat.completions.create(
                model="gpt-4o-mini",
                messages=[{"role": "user", "content": prompt}],
                temperature=0.7
            )

            result_text = response.choices[0].message.content

            self.send_response(200)
            self.send_header('Content-type', 'application/json; charset=utf-8')
            self.end_headers()
            
            # 간단 응답 반환 구조
            response_data = {
                "title": "AI 맞춤 요리",
                "time": "15분",
                "steps": result_text
            }
            self.wfile.write(json.dumps(response_data, ensure_ascii=False).encode('utf-8'))

        except Exception as e:
            self.send_response(500)
            self.send_header('Content-type', 'application/json; charset=utf-8')
            self.end_headers()
            err_res = {"error": str(e)}
            self.wfile.write(json.dumps(err_res, ensure_ascii=False).encode('utf-8'))

# 레시피랩 (RecipeLab AI)

냉장고 속 남는 재료를 활용해 AI가 맞춤형 요리 레시피를 추천해주는 웹 서비스입니다.

## 🛠 기술 스택
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Backend**: Python (Vercel Serverless Functions)
- **AI API**: OpenAI API (GPT-4o-mini)
- **Deployment**: Vercel

## 🚀 실행 및 배포 방법
1. 저장소를 클론합니다.
2. 로컬 환경에서 테스트 시 `.env` 파일에 `OPENAI_API_KEY`를 설정합니다.
3. Vercel에 프로젝트를 연동하고, **Environment Variables**에 `OPENAI_API_KEY`를 등록하여 배포합니다.

## 🔗 배포 URL
- [https://your-recipe-lab.vercel.app](https://your-recipe-lab.vercel.app) (배포된 URL 입력)

## 🔒 환경 변수 설정
- `OPENAI_API_KEY`: OpenAI API 키 (Vercel 대시보드 Settings > Environment Variables에 등록)
